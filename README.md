## 📌 Executive Overview

Current creator-brand collaboration workflows are fundamentally broken and chaotic:
- **Discovery** is fragmented across Instagram, YouTube, and LinkedIn.
- **Negotiation** happens in unrecorded WhatsApp messages and Instagram DMs.
- **Contracts** exist as loose, unversioned PDF attachments.
- **Content Reviews** rely on scattered Google Drive links.
- **Performance & Retention** data vanishes into static, forgotten spreadsheets.

**SYNAPSE OS** replaces this friction with a unified, 13-stage operating workflow:

$$\textbf{Find} \longrightarrow \textbf{Trust} \longrightarrow \textbf{Deal} \longrightarrow \textbf{Create} \longrightarrow \textbf{Approve} \longrightarrow \textbf{Measure} \longrightarrow \textbf{Learn}$$

## 💡 The Breakthrough: 4-State Creator Lifecycle

Marketplaces fail because established creators refuse to manually create another profile. We solve this marketplace cold-start dilemma using a **4-state acquisition model**:

```
┌─────────────────┐       ┌─────────────────┐       ┌─────────────────┐       ┌─────────────────┐
│ 01. Discoverable │ ───>  │  02. Unclaimed  │ ───>  │   03. Claimed   │ ───>  │   04. Active    │
│ Public signals  │       │ Manager routing │       │ Verified owner  │       │ Contracted deal │
└─────────────────┘       └─────────────────┘       └─────────────────┘       └─────────────────┘
```

1. **Discoverable:** Creator indexed from legitimate public data (YouTube statistics, Wikipedia biography).
2. **Unclaimed:** Profile exists publicly; brands reach out via listed verified talent manager/agency contact route (`mgmt@m-agency.com`).
3. **Claimed:** Creator verifies ownership, receiving collaboration tools, rate management, and workspace access.
4. **Active:** Creator executes live campaigns with cryptographically verified contracts, AI script checks, and closed-loop ROI logging.

## 🚀 Core Platform Modules

### 1. 🎛️ Universal Demo Dock (Role Switcher)
- Centered floating dock enabling evaluators to switch perspectives in real time:
  - **Brand Mode:** TechBrand Inc. (Create Briefs, Review Submissions, View Campaign Dashboards).
  - **Claimed Creator:** Alex Vance (Accept Deal Offers, Edit Drafts, Run AI Compliance Checks).
  - **Unclaimed Profile:** Marques B. (Examine Cold-Start Wikipedia context & Manager contact routes).
  - **Deal Verification:** Public Trust Audit view with SHA-256 fingerprint verification.

### 2. 🔍 Creator Discovery Feed & Free Real APIs
- Faceted multi-signal filtering: niche, platform, claimed status, budget sliders, and keyword search.
- **Real YouTube Data API v3:** Fetches public subscriber counts, view velocities, and recent videos.
- **Real MediaWiki REST API:** Dynamically pulls biographical context for unclaimed profiles.
- **Real Twitch Helix API:** Tracks live broadcast game categories and follower counts.
- **Slide-Over Intelligence Drawer:** Deep profile inspection with manager routing cards.

### 3. 🧠 Brand OS Brief Builder & Gemini AI Match Engine
- 4-section structured brief builder (Identity, Audience, Deliverables, Compliance & Talking Points).
- **⚡ Pre-fill CyberFlow Demo Brief:** 1-click shortcut for rapid evaluator demonstrations.
- **Explainable AI Matching:** Powered by Google Gemini Flash (with heuristic offline fallback):
  - Overall Match % score.
  - Transparent reasons why creator fits (e.g., 74% tech audience alignment).
  - Supporting evidence chips (budget fit, engagement rate velocity).
  - Proactive risk & caveat flags.

### 4. 📝 Verified Deal Room & Client-Side PDF Contract
- Split-screen commercial terms editor & live agreement preview.
- Interactive counter-offer simulator (modifies rates, deliverables, and exclusivity windows).
- **Dual Confirmation State Machine:** Requires both `Brand Confirmed ✓` and `Creator Confirmed ✓` to lock deal.
- **jsPDF Agreement Generator:** Client-side generation of branded PDF contracts stamped with unique `Deal ID` (`DEAL-2026-X89B`), cryptographic SHA-256 hash, and dual timestamps.
- **Public Audit Verification Page:** `/deals/verify/[dealId]` for transparent verification.

### 5. 🛡️ Shared Workspace & AI Script Compliance Auditor
- Creator script submission studio with pre-loaded demo scenarios:
  - **Script A (Flawed):** Uses wrong discount code `FALL20` instead of `HACK20`.
  - **Script B (Compliant):** Contains exact CTA phrase and promo code `HACK20`.
- **Gemini Flash Compliance Engine:** Evaluates script against brief requirements in seconds.
- **1-Click Brand Approval:** Unlocks campaign publication.
- **Closed-Loop Retention Memory:** Logs campaign outcome into Alex Vance's portfolio and Brand's historical retention memory.

## ⚡ Quickstart & Setup Guide

### 1. Clone the Repository
```bash
git clone https://github.com/rajmachawal-py/Bnb26_HackRats_maharashtra_round.git
cd Bnb26_HackRats_maharashtra_round
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Configure Environment Variables
Copy the template to create your `.env.local`:
```bash
cp .env.example .env.local
```
Configure your keys (the system includes intelligent fallbacks if keys are omitted):
```env
# Optional for real API enhancements (deterministic fallback included)
GEMINI_API_KEY=your_gemini_api_key_here
YOUTUBE_API_KEY=your_youtube_api_key_here
TWITCH_CLIENT_ID=your_twitch_client_id_here
TWITCH_CLIENT_SECRET=your_twitch_client_secret_here
NEXT_PUBLIC_APP_URL=http://localhost:3000
```

### 4. Run the Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🎭 14-Step Presentation Rehearsal Script

Follow this sequential walkthrough during evaluator judging:

1. **[Brand Mode]** Start on `/campaigns/new`. Click `⚡ Pre-fill CyberFlow Demo Brief` to populate the $2,500 brief targeting tech creators.
2. **[Brand Mode]** Click `Find Creators with Gemini AI`. Observe the top 2 matches: **Alex Vance** (Claimed, 94% Match) and **Marques B.** (Unclaimed, 86% Match).
3. **[Brand Mode]** Open Marques B.'s profile. Highlight the **live Wikipedia biography** and the **verified agency manager contact route** (`mgmt@m-agency.com`), showing how cold-start indexing works.
4. **[Brand Mode]** Select claimed creator **Alex Vance** and review the **Gemini AI Match Explanation Card** showing evidence chips (74% tech audience, $2,500 rate match).
5. **[Brand Mode]** Click `Send Deal Offer`.
6. **[Role Switcher ➔ Creator Mode]** Switch to Alex Vance. Open `/deals/DEAL-2026-X89B`. Review terms and click `Accept & Sign Agreement`.
7. **[Role Switcher ➔ Brand Mode]** Switch back to TechBrand Inc. and confirm terms. Watch the deal state transition to `Dual-Confirmed ✓`.
8. **[Both Roles]** Click `Download Agreement PDF`. Open the generated PDF showing official deliverables, compensation, `Deal ID`, and cryptographic confirmation timestamps.
9. **[Both Roles]** Open `/deals/verify/DEAL-2026-X89B` to show the public audit verification page.
10. **[Role Switcher ➔ Creator Mode]** Open `/campaigns/cyberflow/workspace`. Paste demo **Script A** (contains mistake: mentions code `FALL20` instead of `HACK20`).
11. **[Creator Mode]** Click `Run AI Compliance Check`. Gemini Flash flags the mismatched promo code in an amber warning badge.
12. **[Creator Mode]** Switch to demo **Script B** (compliant code `HACK20` and CTA). Rerun check ➔ 100% Green Pass. Click `Submit for Brand Approval`.
13. **[Role Switcher ➔ Brand Mode]** Brand reviews the compliant submission and clicks `Approve & Mark Published`.
